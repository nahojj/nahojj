# Hi, I'm Johan 👋

I write TypeScript for a living and Vue for fun, which works out nicely
because most days those are the same thing. `strict: true`, obviously.

## 🧰 Things I do

🖖 Most of my time goes into Vue and Nuxt. I like the Composition API, I like
stores that stay small, and I like a component library I can bend to a design
without fighting it. I have strong opinions about `interface` versus `type`
and will defend `as const` over enums at length if you let me. Frameworks
move on, and I move the code with them, one `git log -p` at a time.

🐘 On the other side of the wire there is usually PHP and Laravel, where I look
after the data that matters, the money that moves, and the third-party
services that need to agree with each other without anyone noticing they
exist. Half of backend work is reading `EXPLAIN` output; the other half is
pretending time zones are simple.

🧪 I write tests that earn their keep: unit tests for the rules, end-to-end
tests for the flows where something is at stake. A test that cannot fail is
just a slow comment, and a flaky one is a cry for help.

🚢 And I ship. Small pull requests, a stage before production, a lockfile I
actually read, and a healthy respect for real data, which is usually where
the bug turns out to live. Dependabot and I have an understanding. 🤖
